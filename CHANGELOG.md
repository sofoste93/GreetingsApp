# GreetingsApp 2.0.0 — Event Horizon

- Complete responsive Stargate-inspired interface with animated telemetry.
- Native Java desktop app plus installable offline PWA for phones.
- English, French and German; persistent language setting and built-in help.
- Tested greeting logic, terminal mode, Java runtime bundled in every desktop download.
- Reproducible GitHub Actions builds for Windows, Linux, Intel Mac and Apple Silicon.
- New illustrated learning guide and focused comments for Java learners.

The archives are portable app images: extract, open the `GreetingsApp` folder and run the launcher. No separate Java installation is required.
